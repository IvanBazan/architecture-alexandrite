## Мотивация

Существуют проблемы:

- Заказы пользователей не исполняются в срок. Есть предположение что они не доходят до исполнителей
- Заказы из внешнего API MES теряются тоже в непонятном статусе

Ожидаю получить следующие метрики

Технические:
- Количество ошибок в цепочке запросов
- Процент завершенных заказов
- Время выполнения заказа

Бизнес:
- среднее время обработки заказа
- средняя стоимость инцидентов. например при "потерянных заказах"

## Предлагаемое решение

Покрыть трейсингом запросы проходящие из онлайн магазина и Апи MES

Для реализации предлагается использовать решение на основе OpenTelemetry и Jaeger

## Компромиссы

Доработка MES для трейсинга может быть затруднительной.
Но так как я в будущем предполагаю масштабирование MES по горизонтали с использованием gateway и балансировщика, 
то полагаю что настройка трейсинга через балансировщик сможет стать решением

До реализации этого возможны доработки только своих сервисов

## аспекты безопасности 

- настройка RBAC 
- TLS для всех соединений
- настроить TTL для хранящихся трейсов
- выделенный Namespacе
- аудит запросов к Jaeger UI
